## 🚀 Building from Source

### Prerequisites
1. Install [Typst CLI](https://github.com/typst/typst) (`>= 0.14.0`).
2. Required fonts:
   * **Roboto**
   * **Source Sans 3**
   * **Font Awesome 7 Free / Brands / Solid**

### Compile Commands

```bash
# Build 1-Page CV
typst compile cv_onepage.typ Ahmad_Basharat_Ali_CV_1Page.pdf

# Build 2-Page CV
typst compile cv.typ Ahmad_Basharat_Ali_CV.pdf

# Live Watch / Auto-Reload Mode
typst watch cv_onepage.typ Ahmad_Basharat_Ali_CV_1Page.pdf
```
